▼ 데이터셋 취득

센서 설정을 고정하고 지형·경로·배치를 시드 기반으로 다양화한다. 각 장면 결과는 하나의 sample 폴더에 모인다.

저장할 산출물

    바닥 클러터
    100%=이전 production 밀도 · 기본 200%=암석/자갈·퇴적물의 수와 패치 수를 두 배로 늘려 실제 스와스 안에 집중 배치 · 300%는 취득 시간이 크게 늘 수 있음
    난파선
    100%=이전 난파선 수(대략 14~15척) · 기본 200%=약 28~30척. 90%는 각 조사 leg의 좌우 5~18 m 스와스에 분산 배치해 경로 전체에 GT가 나타남 · 0%=난파선 없음
    난파선 기울기
    각 난파선의 roll과 pitch를 각각 −설정값~+설정값에서 독립적으로 뽑음. 기본 ±90°는 전복·측면 자세까지 포함한다. 엔진은 회전된 메시의 실제 세로 높이를 계산한 뒤 매몰률을 적용하므로, 기울기 때문에 공중에 뜨지 않도록 배치한다. yaw(방위)는 항상 0~360°로 무작위.
    센서
    수직빔/ray support 50° · 고도 80–95% · range_min 0.5 m · range_max는 복각·항로·좌우 스와스 최원거리 해저 95%(상한 70 m)
    수신기 노이즈
    전자잡음의 평균 power 배율. 1=기본, 0=전자잡음 없음, 2=+3.01 dB
    스페클
    월드 좌표에 고정된 복소 미세산란의 diffuse 비율. 1=현재 기본 완전-speckle, 0=미세산란 없이 결정론적 반사만 사용
    반사 텍스처
    해저 반사 전력의 느리고 공간적으로 상관된 변동. CV=0은 끔, 0.25 정도는 약한 패치 변화, 1은 매우 강한 이질성. 전자잡음과 별개
    맵
    available=true인 모든 맵을 섞어 순환
    배경 객체
    암석·모래 퇴적 더미를 여러 패치로 집중 배치하고 소형 군집 member를 확대
    수치 ray 예산
    빈 원거리 계산을 없애고 0.15 m 간격 조건을 지키도록 씬별 산정
    미리보기
    선택 시 각 sample에 지형·오브젝트 탑뷰 저장
    중지
    완료된 세션은 즉시 index.json에 기록되어 그대로 보존
    출력
    samples/scene_NNNNNN/에 장면별 저장
    1. 센서와 출력 항목을 확인한다.
    2. 계획만 생성으로 예상 종료를 확인한다.
    3. 데이터셋 취득 시작을 누른다.
    4. 실행 패널에서 진행률·예상 종료·출력 폴더를 본다. 중지는 완료분을 지우지 않는다.

    ▼ 지난 취득

    데이터셋 취득 설명

    사용자가 고정

    왼쪽 센서·환경: 주파수, 대역폭, 빔폭, 음속·밀도, 신호처리.

    이 탭: 플랫폼, 복각, 노이즈·스페클 기준값, 텍스처, 배치량·기울기.

    씬마다 무작위

    지형 균형 순환 · 경로 길이 25/50/100% · 방위 0–180° · leg 5–7개 · 간격 55–75m.

    고도는 사용 가능 물기둥의 80–95%, 노이즈는 기준값×0.85–1.15, 스페클은 기준값±0.12.

    객체 수는 종류별 범위×배치량이고, 종류·위치·자세·매몰·seed가 바뀐다.

    기하에 따라 자동

    최대 range, ping 간격(0.10–0.20m), 수직·수평 ray 수, 지형 경계 내 실제 경로.

    빔이 닿지 않는 빈 bin·중복 ping을 줄이고, 지형 기복에도 ray 해상도를 유지하기 위해 자동 계산한다.

    자산 라이브러리 —

    제외한 자산은 씬 생성 시 뽑히지 않는다. scene_config.json → excluded_objects 에 저장된다.

    지형 만들기 —

    미리보기는 실제 생성과 같은 함수(make_terrain.build)로 만든다. 생성하면 CSV·씬 JSON 을 소스와 패키지 런타임 양쪽에 쓰고 scene_config.json 에 등록한다. 재빌드·재패킹 불필요.
